# EE 303 Electronics II

Lecture materials for **EE 303 Electronics II**, prepared by **Dr. Ahmed Reda Mohamed**.

This repository currently covers feedback amplifier fundamentals and practical feedback analysis. Each lecture set is available as a PDF for reading and a PowerPoint slide show for presentation.

## Topics covered

### Lecture 01 — Feedback fundamentals

- Positive and negative feedback; forward gain, closed-loop gain, feedback factor, and loop gain.
- Negative-feedback topologies and their input/output connections.
- Benefits and tradeoffs of negative feedback.
- Gain robustness and bandwidth extension.
- Internal disturbance/noise suppression and reduction of in-loop distortion.
- Impedance control and resistance derivations.

### Lectures 02–03 — Practical feedback analysis

- Practical feedback effects and feedback-network loading.
- A step-by-step procedure for practical feedback analysis.
- Series–shunt feedback: worked examples.
- Series–series feedback: worked examples.
- Basic MOSFET amplifier topologies.
- Basic BJT amplifier topologies.

## Using the materials

1. Select **View PDF** in the table to read a lecture on GitHub, or download the PDF for offline study.
2. Select **Download PPSX**, then use GitHub’s download button to save the slide show and open it in Microsoft PowerPoint.
3. Follow the lecture order: **01**, then **02–03**.

The `.ppsx` files are PowerPoint slide shows. GitHub does not display them as an interactive presentation; download them to view the slides.
